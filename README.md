;===============================================================================
; Work & Life App - Personal Local Program (AutoIt3)
;
; Features:
;   1. Task Planner: Add new tasks, set reminder time (HH:MM, 24-hour format. Leave blank for no reminder)
;   2. Task Manager: View all tasks and delete tasks
;   3. F11 key: Toggle fullscreen / windowed mode
;   4. Check reminder time every 10 seconds in the background.
;      A Windows desktop notification will pop up at the bottom-right corner when the time is due.
;      (Each task only alerts once; monitoring stops when the program closes)
;
; Data file: target.ini (Saved in the same folder as the script, no hard-coded disk paths)
